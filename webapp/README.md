# Prototipo VideoQA

FastAPI y React/Vite para la configuración final identificada en `../configs/final_experiment.json`. Inferencia e intervenciones en vivo; asociación visual precomputada con los mismos pesos.

Consultar [instalación, recursos y ejecución](../README.md) y [validación/resultados](../docs/RESULTS.md). El backend rechaza pesos cuyos hashes no coincidan. No se incluyen videos, frames, features ni checkpoints.
